1. The launch prompt included the personal `AGENTS.md` paragraph headed `Jaz Bots`: every Jaz bot coordinates and delegates engineering, however small. Its scope was bots, not ordinary work threads. The platform injects the whole personal file into both contexts. [Shared-file assembly](../../backend/internal/coordinator/prompt.go)
2. Codex's native agent tooling permitted delegation when applicable instructions called for it; it did not require this sound change to be delegated. The screenshot's `/root/contents_diagnosis` was an existing native child, not a new bot chat or a separate saved Jaz thread. [Thread/native-agent distinction](../../backend/internal/templates/jazplatform/shared.tmpl)

The worker added the two notification sound options. Those follow-ups and waits explain the activity rows; none was necessary for the edit. [Notification implementation](../../frontend/src/main/notifications.ts)
4. The failure was treating the bot-only paragraph as applicable, then continuing an unnecessary coordinator/worker workflow. Existing bot-module routing was correct. The initial role-label patch still left policy interpretation to the model; it has been replaced with separate templates and scoped inputs. [Existing routing coverage](../../backend/internal/app/bot_prompt_test.go), [Role-label fix](../../backend/internal/coordinator/prompt.go)

## Findings and changes

**1. Legacy skill copies are accepted and left unchanged.** Commit `5d8cfce1` stopped copying Jaz skills into native CLI profiles on 24 October and left installed copies behind. This thread's native prompt repeated 34 skill names, but no causal link to the delegation was established. The user confirmed that leaving existing copies is acceptable. Automatic retirement has been removed from the proposed fix. [Catalogue contract](../../backend/README.md), [Skill loading](../../backend/internal/skills/skills.go)

**2. Role selection now chooses separate top-level templates.** Stored source types select `bot.tmpl` for bot chats and group seats, and `thread.tmpl` for regular threads, bot workers and routine workers. Shared partials provide common context and output capabilities. Coordinator/delegation policy lives only in the bot template; worker delivery and explicit-only saved-thread creation live only in the thread template. Native Jaz identity no longer repeats competing thread policy. [Selection](../../backend/internal/coordinator/prompt.go), [Thread template](../../backend/internal/templates/jazplatform/thread.tmpl), [Bot template](../../backend/internal/templates/jazplatform/bot.tmpl)

Bot-only personal rules have their own editable root `BOTS.md`, loaded only for bot chats. The actual personal `Jaz Bots` section still requires the user's approval to move out of global `AGENTS.md`; production code does not guess scope by parsing Markdown headings. Bot-home identities also move from natively inherited `AGENTS.md` to explicitly injected `BOTS.md` before ACP starts. Existing `BOTS.md` is preserved. Routine workers keep access to `MEMORY.md` but no longer inherit the saved bot identity prompt. [Startup migration](../../backend/internal/bots/migrate.go), [Bot/routine assembly](../../backend/internal/bots/prompt.go), [Settings](../../frontend/src/renderer/src/components/settings/PersonalizationSettings.tsx)

**3. Personal-file instructions encouraged over-eager edits.** The older shared prompt said to write immediately and that the files did not wait for the user to ask. That wording existed before this week, but was directly relevant to my mistaken personal `AGENTS.md` edit. The replacement distinguishes explicit lasting personal instructions from requests to change Jaz, its prompts, a project or a generated document. The latter belong in project files. Personal instructions themselves were not changed by this fix. [Updated boundary](../../backend/internal/templates/jazplatform/shared.tmpl)

**4. Memory lookup quality can change independently of the main model.** Saved memory-search records show Luna/low on 25 and 27 October, Astra/xhigh on 29 October, and Luna/medium on 31 October and 1 November. Recent lookups in this conversation used Luna/medium. The 31 October commit `5b53a6c1` changed unspecified memory-worker defaults to Luna/low and tightened selection of the requested model; explicit settings still take precedence. These receipts do not establish whether the observed switch came solely from the default change or from saved settings. Weaker lookup answers could affect any primary agent using the memory tool. No memory-model setting was changed in this fix. [Worker defaults](../../backend/internal/settings/agents.go), [Explicit settings](../../backend/internal/settings/memory.go), [Memory-search runner](../../backend/internal/memorysearch/runner.go)

**5. Broad context is an observation, not an established cause.** This thread's first native request reported 39,877 input tokens overall, including native instructions, tools, user input and Jaz context. Its launch extension contained approximately 66,600 characters of Jaz context plus a 29,200-character native skill catalogue. Daily memory is also injected whole: the 25 October file currently measures 127,631 characters. This fix does not change skill copies, memory injection or provider-owned context/compaction behavior. [Memory injection](../../backend/internal/coordinator/memory.go), [Platform assembly](../../backend/internal/coordinator/prompt.go)
