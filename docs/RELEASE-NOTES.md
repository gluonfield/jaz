Changes since v0.0.285:

- Agents draw a chart, diagram or other visual whenever it explains the answer better than text, including when it was not asked for. Charts follow fuller design rules: a fixed series colour order, direct labels and readable axes.
- The instructions every thread starts with are about 9,000 characters shorter. Artifact guidance is read when an agent first draws, and memory rules are four lines.
- Agents can look up any service Jaz can connect to with `connections_search`, which returns its connected accounts and connect link. A thread's prompt lists connected accounts only.
- Microsoft Copilot can run as an agent with a work or school account.
